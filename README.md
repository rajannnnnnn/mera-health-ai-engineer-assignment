# mera.health — AI Engineer Take-Home

The untouched starter assignment is stored in [`ai-engineer-take-home.zip`](./ai-engineer-take-home.zip). `PLAN.md` was committed first, before any implementation work.

Extract locally with:

```bash
unzip ai-engineer-take-home.zip
cd ai-engineer-take-home
python -m pip install -r requirements.txt
python extract.py reports/report_01.pdf
```

The archive contains the starter extractor, reports, labels, and task brief. The evaluation and implementation work are not yet complete. Never commit API credentials.
